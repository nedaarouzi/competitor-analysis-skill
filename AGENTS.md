# Agent instructions

This repository contains an open skill for marketing competitor analysis.

- The skill lives in `skills/competitor-analysis/SKILL.md`. Read it and follow it when the user asks for competitor research, an ad landscape or go-to-market research.
- Required inputs: a company name and three competitors. Do not ask for anything else unless it is missing and essential.
- Use public data only. Never invent figures. Mark anything you could not find as "not available".
- Present estimates as ranges with a confidence level, and say clearly that they show direction, not truth.

When editing this repository: keep `SKILL.md` under 500 lines, keep the `name` field identical to the folder name, and do not add company-confidential data.
